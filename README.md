# Exp - 2 LIBRARY MANAGEMENT SYSTEM

# AIM:
To design and draw UML diagrams for the LIBRARY MANAGEMENT SYSTEM

# SRS (Procedure):

1. Identify the main actors such as **Librarian**, **Member**, and **Administrator**.
2. Determine the main functions like **Add Books**, **Issue Books**, **Return Books**, and **Search Books**.
3. Draw the **Use Case Diagram** linking actors with their respective actions.
4. Develop **Class, Sequence, package, communication and Activity Diagrams** to show system structure and behavior.
5. Review and verify all relationships to ensure the UML diagrams correctly represent the **Library Management System**.
